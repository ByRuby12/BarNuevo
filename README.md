# BarNuevo

## 📋 Sobre este proyecto

**BarNuevo** es una web de carta digital para un establecimiento de hostelería, creada para presentar su menú de forma moderna, rápida y adaptada a móviles y ordenadores.

La web permite organizar los productos por categorías y mostrar nombres, descripciones, precios, imágenes e información de alérgenos. También cuenta con una sección de contacto con los datos del establecimiento, enlaces de valoración, teléfono y servicios de entrega disponibles.

Además, incorpora cambio de idioma, redes sociales, galería, diseño responsive y una estructura de contenidos configurable mediante archivos de datos, permitiendo adaptar la carta a diferentes establecimientos sin tener que modificar toda la web.
